# TS/CTS 学习算法数学测评方法调研

日期：2026-11-19。范围：本项目合成对话中固定臂、TS、LaplaceCTS 与 RuleRouter 的效果、成本及不确定性。本文是文献调研和项目适配建议，不是正式结果，也不改变已约定的实验协议。

## 1. 调研结论与方法地图

建议以当前约定的“对话级平均效用差 + 配对 bootstrap”作为主分析，同时报告准确率和成本分量。配对 t 检验可以作为预先声明的稳健性检查；符号检验、Wilcoxon、贝叶斯 ROPE 回答不同问题，不应在看完结果后选择最显著的方法。

| 方法 | 回答的问题 | 主要假设/限制 | 本项目定位 |
|---|---|---|---|
| 效用、准确率、成本与 Pareto 比较 | 是否值得额外输入成本 | 成本权重体现偏好；代理成本不是真实费用 | 必报描述与主指标 |
| 配对 bootstrap | 平均效用提升的区间有多宽 | 对话可视作独立、同场景代表性样本；有限样本覆盖非保证 | 主分析 |
| 配对 t 检验/区间 | 总体平均差是否为零 | 独立差值；精确小样本推断要求差值正态 | 补充敏感性 |
| 配对符号翻转检验 | 在可交换/对称零假设下差异是否异常 | 不是仅凭均值为零就成立 | 有条件采用 |
| Wilcoxon 符号秩 | 对称位置差异是否为零 | 差值对称、零差和并列需处理；不等于一般均值检验 | 探索性 |
| 符号检验/胜率 | 新对话中胜出的频率 | 忽略提升幅度；平局规则必须预设 | 可解释性补充 |
| 贝叶斯差值模型 + ROPE | 提升、实用等效、退步各有多大后验概率 | 依赖似然、先验、等效阈值 | 后续扩展 |
| Friedman + 事后比较 | 多方法整体排名是否不同 | 独立区组；排名丢失效应幅度 | 七方法探索，不替代主比较 |
| 阶段效应/累计差 | 收益何时出现，突变后如何变化 | 多窗口/逐点检查存在多重性 | 机制解释 |

以上定位是针对本项目结构的判断，不是文献直接验证过本项目。

## 2. 先定义统计单位与估计目标

设 s 为场景，d 为独立生成对话，r 为算法 seed，t 为题目，m 为方法：

$$u_{sdrtm}=y_{sdrtm}-\lambda C_{sdrtm}/512,\quad \lambda=0.5.$$

$$\bar U_{sdm}=\frac1R\sum_r\frac1T\sum_t u_{sdrtm},\quad D_{sd}=\bar U_{sd,CTS}-\bar U_{sd,b_s},\quad \widehat\Delta_s=\frac1{n_s}\sum_dD_{sd}.$$

b_s 是只用开发数据选出的固定臂。正式重采样不重新选 b_s，因此结论条件于本次开发选择。每场景 n=30，两个算法 seed 不是 n=60，300 题更不是 300 个独立样本。题目共享历史，学习器也随反馈更新。

使用同一条对话比较方法可控制该对话的难度；分析必须保留 scenario/seed 的配对。算法 seed 只有两个时，对算法随机性平均的估计仍有限；对话 bootstrap 并不会自动充分刻画所有未运行 seed 的波动。不要直接套用交叉验证的相关性修正公式：本项目没有 k 折训练/测试重叠结构。

## 3. 指标：效果、成本和权重敏感性

定义 A=mean(y)、C=mean(cost)，则同一汇总方式下：

$$\Delta_U=\Delta_A-\lambda\Delta_C/512.$$

同时给出 ΔA、ΔC，可判断效用提升来自正确率还是输入节省。coverage 和 outdated 用来解释失败；coverage=1 不保证答对，旧陈述也可能仍含正确值，因此它们不能替代 y。

若方法甲准确率不低于乙且成本不高于乙，并至少一项严格优于乙，可称其在这些点估计上 Pareto 占优；这不等于已证明总体占优，应结合配对区间。

对固定的两条行为轨迹，如果 ΔC≠0，效用排序的交点为 λ*=512ΔA/ΔC，仅在所研究 λ 范围有解释意义。TS/CTS 的 choose 本身减去成本，所以改变 λ 后重新评价算法必须重新回放；只重算已保存轨迹回答的是“既定行为在新评分偏好下如何”，不是新策略效果。成本是正则长度代理，不能解释成 API 金额或真实 token 数。

## 4. 配对 bootstrap：当前主方案

每场景从 n 个对话索引有放回抽 n 个，用同一索引保留方法—基线配对，计算 B 次均值差 Δ*。95% 百分位区间取 Q(.025)、Q(.975)。SciPy 提供 percentile、basic 和 BCa，并可通过 paired 参数共同重采样索引；默认方法不一定等于本项目当前实现，复现时须显式指定。[SciPy bootstrap](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)

本项目当前采用 percentile；BCa 考虑偏差与加速项，可以作为冻结前的候选，但离散/退化样本也可能不稳定。不能因某种区间更容易排除零而选它。B=2,000 与 10,000 的比较只检查 Monte Carlo 端点稳定性，不增加独立数据或保证覆盖率。

两个预定场景构成两个主比较，每个使用 97.5% 双侧区间，即分位点 .0125/.9875。若各区间确有相应覆盖率，Bonferroni 联合错误上界为 2×.025=.05；bootstrap 有限样本覆盖是近似的，因此不能宣称严格有限样本保证。

Agarwal 等强调少量运行下仅比较均值/中位数会掩盖不确定性，提倡区间及性能分布描述。其工作针对多任务深度 RL，不能直接把任务分层与本项目对话层级等同。[Agarwal et al., 2021](https://papers.nips.cc/paper/2021/hash/f514cec81cb148559cf475e7426eed5e-Abstract.html)

## 5. 配对 t 检验与均值区间

令 s_D 为对话差值样本标准差：

$$t=\bar D/(s_D/\sqrt n),\qquad CI=\bar D\pm t_{n-1,1-\alpha/2}s_D/\sqrt n.$$

零假设是 E[D]=0。差值独立且正态时有精确 t 参考分布；非正态时依赖近似，不能因 n=30 就保证可靠。查看离群值与差值分布，若与 bootstrap 结论不同，如实讨论。不要对 CTS 与基线使用不配对的独立样本 t 检验。[SciPy ttest_rel](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_rel.html)

建议仅列为预声明补充分析，保留原主区间。s_D=0 时须明确退化情形，不能静默除零。

## 6. 符号翻转、符号秩与胜率

### 6.1 配对符号翻转

构造 D*_d=ε_d D_d，ε_d∈{−1,+1}，比较 |mean(D*)| 与 |mean(D)|。随机抽 B 次时常用 p=(1+#极端样本)/(B+1)。两方法在配对内交换标签对应 SciPy 的 permutation_type='samples'。[SciPy permutation_test](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.permutation_test.html)

关键限制：需要零假设下配对标签可交换，或独立差值分布对零对称等足够条件。算法标签并非随机分配，仅有 E[D]=0 不能保证这个检验有效。它不能被包装成“完全无假设”的替代品。

### 6.2 Wilcoxon 符号秩

对非零 |D_d| 排秩，计算 W+=Σ rank(|D_d|)I(D_d>0)。标准位置解释依赖差值对称，零差、并列和浮点误差影响精确分布及实现。它与检验平均效用差不是同一个问题。[SciPy wilcoxon](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.wilcoxon.html)

### 6.3 符号检验与对话胜率

令 W=#(D>0)、L=#(D<0)。排除零差时，在独立非平局对话且正负概率各半的零假设下，W~Binomial(W+L,.5)。可报告 W/(W+L)，同时单列平局率；这估计条件于非平局的胜率。若描述“胜记1、平记0.5”，分母和估计目标均不同，不能直接复用上述二项检验。

胜率便于解释“有多少对话受益”，但不反映幅度：多数小胜仍可能被少数大败抵消，因此必须与平均效应并报。

## 7. 贝叶斯测评与实际等效

Benavoli 等讨论通过后验概率比较学习算法的替代框架；它提供另一种解释方式，不意味着本项目必须放弃当前频率学派方案。[Benavoli et al., 2017](https://jmlr.org/papers/v18/16-305.html)

项目可探索以下差值模型（这里是拟议适配，并非直接复现论文）：

$$D_{sd}\sim Normal(\mu_s,\sigma_s^2),\quad \mu_s\sim Normal(0,\tau^2).$$

为 σ 选择正值先验并做先验敏感性；离群值明显时可研究 Student-t 似然。设实际等效阈值 δ=.02，报告 P(μ>δ|D)、P(|μ|≤δ|D)、P(μ<−δ|D)。δ 的意义须先确认；这三类概率依赖所选模型与先验。

ROPE 可区分“接近零”与“证据不足”。频率学派 p>.05 不证明等效，95% 置信区间也不是参数有95%概率落在区间内。学习器内部的 Beta/Laplace 后验仅用于选臂，不等于算法整体效用差的后验，不能直接拿来做这项比较。只有两个场景时不宜过度声称复杂跨场景层级模型已被充分识别。

## 8. 多方法排名与多重比较

对 n 条独立对话内的 k 个方法按效用排名，平均秩为 R̄_m。无并列情况下 Friedman 统计量：

$$Q=\frac{12n}{k(k+1)}\sum_m\bar R_m^2-3n(k+1).$$

存在并列时需修正。整体检验不指出哪一对不同，事后检验还需控制多重比较。Demšar 讨论多数据集算法比较中的 Wilcoxon/Friedman 及事后分析；本项目可以借鉴区组思想，但“同一机制的对话”不是“多样真实数据集”，推广范围更窄。[Demšar, 2006](https://www.jmlr.org/beta/papers/v7/demsar06a.html)

七方法有21对比较。主检验仍只保留两个场景的预定 CTS—固定基线对比，其余作为探索。若正式增加比较族，可在冻结前考虑 Holm：排序 p_(i)，依次比较 α/(K−i+1)，遇首个不拒绝则停止。不得结果出来后删掉不显著比较以缩小 K。

也有基于 Dirichlet process 的贝叶斯多算法比较方法，可联合考虑比较依赖，但增加了建模与验证成本，当前首轮交付不必实现。[Benavoli et al., 2015](https://proceedings.mlr.press/v37/benavoli15.html)

## 9. 在线适应、阶段分析与 regret 边界

累计配对效用差可写为 G_d(t)=Σ_{j≤t}(u_CTS,j−u_baseline,j)，先在每条对话内平均算法 seed，再跨对话汇总。逐点 bootstrap 形成的95%区间不构成整条曲线的同时95%带，不应挑某个时刻作为新主结论。

abrupt 可按预定 t=0…149 与150…299分别求对话均值差，观察突变前后变化；全程仍是主指标。阶段差可进一步对每条对话计算 D_post−D_pre，不能把两段当独立对话。

固定基线累计差不是理论 regret。若全臂表可用，可描述 Σ_t[max_a u_ta−u_t,a_t] 为“逐题事后 oracle 差距”，但 oracle 看到了未选臂结果、可能逐题换臂，属于更强参照，不等同于期望奖励意义下的理论 regret。学习器仍只能更新所选反馈。
